Questions fréquentes

Comment installer l'extension ?

Cliquez sur « Installer l'extension », téléchargez le pack, puis chargez-le dans Chrome via chrome://extensions en mode développeur.

Est-ce sécurisé ?

Absolument. Aucun mot de passe demandé, aucun fichier Roblox modifié. Code open-source vérifiable.

Quels jeux sont supportés ?

Toutes les expériences Roblox : Adopt Me, Brookhaven, Jailbreak, Blox Fruits et bien plus encore.
